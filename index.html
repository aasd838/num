1.1 ما هي الطرق العددية؟

الطرق العددية هي أساليب رياضية تصف حل المشكلات في خطوات متسلسلة تسمى الخوارزمية (Algorithm). تحتوي على عمليات حسابية (جمع، طرح، ضرب، قسمة) وشروط وأوامر تُنفذ بلغة برمجة مثل MATLAB أو C++ أو FORTRAN.

المتطلبات السابقة:

  • مهارات رياضية أساسية
  • التفاضل والتكامل التطبيقي (Applied Calculus)
  • الجبر الخطي (Linear Algebra)
  • المعادلات التفاضلية العادية (ODE)

1.3 مصادر الخطأ العددي

الخطأ المطلق: E_abs = |x* - x|

الخطأ النسبي: E_rel = |x* - x| / |x*| × 100%
  • خطأ القطع (Truncation Error): استبدال عملية لا نهائية بمنتهية (مثل قطع متسلسلة تايلور)
  • خطأ التقريب (Round-off Error): تمثيل الأرقام بعدد محدود من الخانات في الحاسوب
% ============================================
% المحاضرة 1: حساب الخطأ العددي - MATLAB
% ============================================
clc; clear;
exact = 8/3;
approx = 2.667;
abs_err = abs(exact - approx);
rel_err = abs_err / abs(exact) * 100;
fprintf('القيمة الحقيقية = %.6f\n', exact);
fprintf('القيمة التقريبية = %.6f\n', approx);
fprintf('الخطأ المطلق = %.6f\n', abs_err);
fprintf('الخطأ النسبي = %.4f%%\n', rel_err);

2.1 الصيغة العامة للنظام الخطي

a₁₁x₁ + a₁₂x₂ + ... + a₁ₙxₙ = b₁
a₂₁x₁ + a₂₂x₂ + ... + a₂ₙxₙ = b₂
⋮
aₘ₁x₁ + aₘ₂x₂ + ... + aₘₙxₙ = bₘ

صيغة المصفوفة: Ax = b

حيث A مصفوفة m×n ، و b متجه m×1 ، و x متجه المجهولات n×1

تصنيف الأنظمة:

النوعالشرطعدد الحلول
محدد تماماً (Well-determined)m = nحل وحيد / لا حل / لا نهائي
غير محدد (Under-determined)m < nلا حل / لا نهائي
محدد زائد (Over-determined)m > nلا حل / حل وحيد

2.2 الحل بالمصفوفة العكسية

إذا كانت A قابلة للعكس (det(A) ≠ 0):

x = A⁻¹ · b

📝 مثال: الحل بالمصفوفة العكسية

حل النظام: x₁ + x₂ = 3 ، x₁ - x₂ = 1

الحل:

A = [1, 1; 1, -1] ، b = [3; 1]

det(A) = (1)(-1) - (1)(1) = -2 ≠ 0 ✓

A⁻¹ = (1/-2)·[-1, -1; -1, 1] = [0.5, 0.5; 0.5, -0.5]

x = A⁻¹·b = [0.5×3 + 0.5×1 ; 0.5×3 - 0.5×1] = [2 ; 1]

2.3 طريقة حذف غاوس (Gauss Elimination)

تتكون من مرحلتين:

  1. مرحلة الحذف (Elimination): تحويل المصفوفة الموسعة إلى مثلثية علوية في (n-1) خطوة باستخدام عمليات الصفوف الأولية
  2. مرحلة التعويض الخلفي (Back Substitution): حل النظام المثلثي

صيغة التعويض الخلفي:

xₙ = bₙ / aₙₙ

xᵢ = (bᵢ - Σⱼ₌ᵢ₊₁ⁿ aᵢⱼ·xⱼ) / aᵢᵢ
حيث i = n-1, n-2, ..., 1

📝 مثال: حذف غاوس (من الملف)

حل النظام التالي بطريقة غاوس:

المصفوفة الموسعة الابتدائية:

[2, 1, -1 | 1]

[3, 2, 1 | 7]

[1, -1, 2 | 1]

الخطوة 1 - الحذف:

R₂ ← R₂ - (3/2)R₁ → [0, 0.5, 2.5 | 5.5]

R₃ ← R₃ - (1/2)R₁ → [0, -1.5, 2.5 | 0.5]

الخطوة 2 - الحذف:

R₃ ← R₃ + 3R₂ → [0, 0, 10 | 17]

التعويض الخلفي:

x₃ = 17/10 = 1.7

0.5x₂ + 2.5(1.7) = 5.5 → x₂ = 2.5

2x₁ + 2.5 - 1.7 = 1 → x₁ = 0.1

خوارزمية غاوس الكاملة:

% ============================================
% المحاضرة 2: حذف غاوس - MATLAB
% ============================================
clc; clear;
A = [2 1 -1; 3 2 1; 1 -1 2];
b = [1; 7; 1];
n = length(b);
Ab = [A b]; % المصفوفة الموسعة

% ─── المرحلة 1: الحذف ───
for i = 1:n-1
    % Partial Pivoting: اختيار أكبر عنصر محوري
    [~, p] = max(abs(Ab(i:n, i)));
    p = p + i - 1;
    if p ~= i
        Ab([i p], :) = Ab([p i], :); % تبديل الصفوف
    end
    for j = i+1:n
        m = Ab(j,i) / Ab(i,i);
        Ab(j,:) = Ab(j,:) - m * Ab(i,:);
    end
end

% ─── المرحلة 2: التعويض الخلفي ───
x = zeros(n,1);
x(n) = Ab(n,n+1) / Ab(n,n);
for i = n-1:-1:1
    x(i) = (Ab(i,n+1) - Ab(i,i+1:n)*x(i+1:n)) / Ab(i,i);
end

fprintf('الحل بطريقة غاوس:\n');
for i = 1:n
    fprintf('x%d = %.6f\n', i, x(i));
end

المحاضرة 3: الطرق التكرارية للأنظمة الخطية

🎯 الأهداف التعليمية

  1. فكرة الطرق التكرارية والتقارب
  2. تطبيق طريقة جاكوبي (Jacobi Method)
  3. تطبيق طريقة غاوس-سايدل (Gauss-Seidel Method)
  4. التمييز بين الطريقتين
  5. شرط التوقف: |x⁽ᵏ⁺¹⁾ - x⁽ᵏ⁾| ≤ ε

3.1 الفكرة العامة

الطرق التكرارية لا تحل النظام مباشرة، بل تولد متتالية من التقريبات:

x⁽⁰⁾, x⁽¹⁾, x⁽²⁾, ... → x (الحل)

x⁽ᵏ⁺¹⁾ = C·x⁽ᵏ⁾ + d ، k = 0, 1, 2, ...

3.2 طريقة جاكوبي (Jacobi)

xᵢ⁽ᵏ⁺¹⁾ = (1/aᵢᵢ) × [bᵢ - Σⱼ≠ᵢ aᵢⱼ·xⱼ⁽ᵏ⁾]

النقطة الجوهرية: جميع القيم في الطرف الأيمن من التكرار السابق k

لنظام 3×3:

x₁⁽ᵏ⁺¹⁾ = (1/a₁₁)[b₁ - a₁₂x₂⁽ᵏ⁾ - a₁₃x₃⁽ᵏ⁾]
x₂⁽ᵏ⁺¹⁾ = (1/a₂₂)[b₂ - a₂₁x₁⁽ᵏ⁾ - a₂₃x₃⁽ᵏ⁾]
x₃⁽ᵏ⁺¹⁾ = (1/a₃₃)[b₃ - a₃₁x₁⁽ᵏ⁾ - a₃₂x₂⁽ᵏ⁾]

3.3 طريقة غاوس-سايدل (Gauss-Seidel)

x₁⁽ᵏ⁺¹⁾ = (1/a₁₁)[b₁ - a₁₂x₂⁽ᵏ⁾ - a₁₃x₃⁽ᵏ⁾]
x₂⁽ᵏ⁺¹⁾ = (1/a₂₂)[b₂ - a₂₁x₁⁽ᵏ⁺¹⁾ - a₂₃x₃⁽ᵏ⁾]
x₃⁽ᵏ⁺¹⁾ = (1/a₃₃)[b₃ - a₃₁x₁⁽ᵏ⁺¹⁾ - a₃₂x₂⁽ᵏ⁺¹⁾]

الفرق الجوهري: نستخدم القيم المحدثة فور توفرها (x₁⁽ᵏ⁺¹⁾ في حساب x₂⁽ᵏ⁺¹⁾)

3.4 شرط التوقف

|xᵢ⁽ᵏ⁺¹⁾ - xᵢ⁽ᵏ⁾| ≤ ε (التسامح المعطى)

النظام: 3u + v = 5 ، u + 2v = 5 ، التخمين الأولي: (u₀,v₀) = (0,0)

إعادة الكتابة: u = (5-v)/3 ، v = (5-u)/2

الخلاصة من الملف: "Gauss-Seidel often converges faster than Jacobi if the method is convergent"

% ============================================
% المحاضرة 3: غاوس-سايدل - MATLAB
% ============================================
clc; clear;
A = [3 1; 1 2];
b = [5; 5];
n = length(b);
x = zeros(n,1); % التخمين الأولي
tol = 1e-6;

fprintf('  k  |   u     |   v     | الخطأ\n');
fprintf('─────────────────────────────────\n');

for k = 1:100
    x_old = x;
    for i = 1:n
        s = 0;
        for j = 1:n
            if j ~= i
                s = s + A(i,j) * x(j); % قيم محدثة فوراً
            end
        end
        x(i) = (b(i) - s) / A(i,i);
    end
    err = max(abs(x - x_old));
    fprintf(' %2d | %.4f | %.4f | %.6f\n', k, x(1), x(2), err);
    if err < tol
        fprintf('\nتقارب عند التكرار %d\n', k);
        break;
    end
end
fprintf('\nالحل النهائي: u = %.6f, v = %.6f\n', x(1), x(2));

  2. حساب عدد التكرارات المطلوبة

4.1 شرط وجود جذر (نظرية القيمة المتوسطة)

إذا كانت f متصلة على [a,b] و f(a)·f(b) < 0
→ يوجد جذر واحد على الأقل في [a,b]

4.2 طريقة التنصيف (Bisection / Interval Halving)

الفكرة:

  1. نبدأ بقيمتين a و b تحصران جذرًا: f(a)·f(b) < 0
  2. نحسب المنتصف: c = (a+b)/2
  3. نحدد أي نصف يحتوي الجذر بناءً على إشارة f(c)
  4. نكرر حتى الوصول للدقة المطلوبة

عدد التكرارات المطلوبة:

n ≥ ln((b-a)/ε) / ln(2)

خوارزمية التنصيف:

  1. المدخلات: a, b بحيث f(a)·f(b) < 0 ، والتسامح ε
  2. كرر:
  3. احسب c = (a+b)/2
  4. إذا f(a)·f(c) < 0 → b = c
  5. وإلا → a = c
  6. حتى (b-a)/2 < ε أو f(c) = 0
  7. النتيجة: c هو تقريب الجذر

4.3 طريقة الوضع الكاذب (False Position / Regula Falsi)

c = [a·f(b) - b·f(a)] / [f(b) - f(a)]

مشابهة للتنصيف لكن بدل المنتصف نستخدم نقطة تقاطع القاطع مع محور x

% ============================================
% المحاضرة 4: التنصيف + الوضع الكاذب - MATLAB
% ============================================
clc; clear;
f = @(x) x.^3 - x - 1;
a = 0; b = 1; tol = 1e-6;

% ─── التنصيف ───
if f(a)*f(b) >= 0, error('لا يوجد تغيير إشارة'); end
a1=a; b1=b;
for n = 1:100
    c = (a1+b1)/2;
    if abs(f(c)) < tol || (b1-a1)/2 < tol
        fprintf('التنصيف: الجذر = %.8f بعد %d تكرار\n', c, n);
        break;
    end
    if f(a1)*f(c) < 0, b1 = c; else, a1 = c; end
end

% ─── الوضع الكاذب ───
a2=a; b2=b;
for n = 1:100
    c = (a2*f(b2) - b2*f(a2)) / (f(b2) - f(a2));
    if abs(f(c)) < tol
        fprintf('الوضع الكاذب: الجذر = %.8f بعد %d تكرار\n', c, n);
        break;
    end
    if f(a2)*f(c) < 0, b2 = c; else, a2 = c; end
end

5.1 طريقة نيوتن-رافسون

أسرع الطرق تقاربًا. تتطلب تخمين أولي x₀ ومشتقة الدالة.

xᵢ₊₁ = xᵢ - f(xᵢ) / f'(xᵢ) ، i = 0, 1, 2, ...

📝 مثال من الملف: نيوتن

f(x) = x³ - x - 1 ، التخمين: x₀ = 0.7

f'(x) = 3x² - 1

الصيغة: xᵢ₊₁ = xᵢ - (xᵢ³ - xᵢ - 1)/(3xᵢ² - 1)

خوارزمية نيوتن-رافسون:

  1. المدخلات: تخمين أولي p₀ ، تسامح TOL ، أقصى تكرارات N
  2. الخطوة 1: عيّن i = 1
  3. الخطوة 2: بينما i ≤ N نفّذ الخطوات 3-6
  4. الخطوة 3: احسب p = p₀ - f(p₀)/f'(p₀)
  5. الخطوة 4: إذا |p - p₀| < TOL → اطبع p وتوقف (نجاح)
  6. الخطوة 5: عيّن i = i + 1
  7. الخطوة 6: عيّن p₀ = p (تحديث)
  8. الخطوة 7: اطبع "الطريقة فشلت بعد N تكرار" وتوقف

5.2 طريقة القاطع (Secant Method)

مشابهة لنيوتن لكنها تستبدل المشتقة بـ خارج قسمة الفروق:

f'(xᵢ) ≈ [f(xᵢ) - f(xᵢ₋₁)] / (xᵢ - xᵢ₋₁)

الصيغة:
xᵢ₊₁ = xᵢ - f(xᵢ)·(xᵢ - xᵢ₋₁) / [f(xᵢ) - f(xᵢ₋₁)]

الفرق: تحتاج نقطتين أوليتين (x₀, x₁) بدل نقطة واحدة + مشتقة

% ============================================
% المحاضرة 5: نيوتن + القاطع - MATLAB
% ============================================
clc; clear;
f = @(x) x.^3 - x - 1;
df = @(x) 3*x.^2 - 1;

% ─── طريقة نيوتن ───
x = 0.7; tol = 1e-8;
fprintf('نيوتن:\n i | x_i\n');
for i = 0:50
    fprintf(' %d | %.10f\n', i, x);
    x_new = x - f(x)/df(x);
    if abs(x_new - x) < tol, break; end
    x = x_new;
end

% ─── طريقة القاطع ───
x0 = 0; x1 = 1;
fprintf('\nالقاطع:\n i | x_i\n');
for i = 0:50
    fprintf(' %d | %.10f\n', i, x1);
    x2 = x1 - f(x1)*(x1-x0)/(f(x1)-f(x0));
    if abs(x2-x1) < tol, break; end
    x0 = x1; x1 = x2;
end

المحاضرات 6-7-8: الاستكمال الرياضي (Interpolation)

🎯 الأهداف التعليمية

  1. الطريقة العامة (General Method) - مصفوفة فانديرموند + قاعدة كرامر
  2. طريقة لا جرانج (Lagrange Interpolation)
  3. طريقة فروق نيوتن المقسمة (Newton Divided Differences)

6.1 تعريف الاستكمال

الدالة p(x) تستكمل نقاط البيانات (xᵢ, yᵢ) إذا كانت تمر بجميع النقاط:

p(xᵢ) = yᵢ ، لكل i = 0, 1, ..., n-1

6.2 الطريقة العامة (General Method)

p(x) = a₀ + a₁x + a₂x² + ... + aₙ₋₁xⁿ⁻¹

بالتعويض بكل نقطة بيانات نحصل على نظام خطي من n معادلة في n مجهول (a₀, a₁, ..., aₙ₋₁)

يُحل النظام باستخدام قاعدة كرامر (Cramer's Rule):

aᵢ = det(Aᵢ) / det(A)

📝 مثال من الملف: الطريقة العامة

النقاط: (0,1), (1,2), (2,0), (3,-1)

4 نقاط → كثير حدود من الدرجة 3:

p(x) = a₀ + a₁x + a₂x² + a₃x³

النظام:

a₀ = 1

a₀ + a₁ + a₂ + a₃ = 2

a₀ + 2a₁ + 4a₂ + 8a₃ = 0

a₀ + 3a₁ + 9a₂ + 27a₃ = -1

بالحل بقاعدة كرامر:

p(x) = 1 + (23/6)x - (7/2)x² + (2/3)x³

7.1 طريقة لا جرانج (Lagrange)

p(x) = Σᵢ₌₀ⁿ⁻¹ yᵢ · Lᵢ(x)

حيث: Lᵢ(x) = Πⱼ≠ᵢ (x - xⱼ)/(xᵢ - xⱼ)

📝 مثال من الملف: لا جرانج

النقاط: (0,-3), (1,1), (2,2), (4,7)

دوال الأساس:

L₀(x) = (x-1)(x-2)(x-4) / [(0-1)(0-2)(0-4)] = (x-1)(x-2)(x-4)/(-8)

L₁(x) = x(x-2)(x-4) / [(1-0)(1-2)(1-4)] = x(x-2)(x-4)/3

L₂(x) = x(x-1)(x-4) / [(2-0)(2-1)(2-4)] = x(x-1)(x-4)/(-4)

L₃(x) = x(x-1)(x-2) / [(4-0)(4-1)(4-2)] = x(x-1)(x-2)/24

كثير الحدود:

p(x) = -3·L₀(x) + 1·L₁(x) + 2·L₂(x) + 7·L₃(x)

بالتبسيط: p(x) = -3 + (23/4)x - (19/8)x² + (1/8)x³

8.1 فروق نيوتن المقسمة (Newton Divided Differences)

f[xᵢ] = f(xᵢ)

f[xᵢ,xⱼ] = (f(xⱼ) - f(xᵢ)) / (xⱼ - xᵢ)

f[xᵢ,xⱼ,xₖ] = (f[xⱼ,xₖ] - f[xᵢ,xⱼ]) / (xₖ - xᵢ)

كثير حدود نيوتن:

p(x) = f[x₀] + f[x₀,x₁](x-x₀) + f[x₀,x₁,x₂](x-x₀)(x-x₁) + ...

📝 مثال من الملف: فروق نيوتن

النقاط: (0,1), (2,2), (3,4)

جدول الفروق المقسمة:

xf[x]f[xᵢ,xᵢ₊₁]f[xᵢ,xᵢ₊₁,xᵢ₊₂]
01(2-1)/(2-0) = 0.5(2-0.5)/(3-0) = 0.5
22(4-2)/(3-2) = 2
34

كثير الحدود:

p(x) = 1 + 0.5(x-0) + 0.5(x-0)(x-2)

p(x) = 1 + 0.5x + 0.5x² - x

p(x) = 0.5x² - 0.5x + 1

% ============================================
% المحاضرات 6-8: الاستكمال - MATLAB
% ============================================
clc; clear;

% ─── لا جرانج ───
x_data = [0 1 2 4];
y_data = [-3 1 2 7];
n = length(x_data);

syms x;
p = 0;
for i = 1:n
    Li = 1;
    for j = 1:n
        if j ~= i
            Li = Li * (x - x_data(j)) / (x_data(i) - x_data(j));
        end
    end
    p = p + y_data(i) * Li;
end
p = simplify(expand(p));
fprintf('لا جرانج: p(x) = %s\n', char(p));

% ─── فروق نيوتن ───
x2 = [0 2 3]; y2 = [1 2 4];
n2 = length(x2);
DD = zeros(n2,n2);
DD(:,1) = y2';
for j = 2:n2
    for i = 1:n2-j+1
        DD(i,j) = (DD(i+1,j-1)-DD(i,j-1))/(x2(i+j-1)-x2(i));
    end
end
fprintf('\nجدول الفروق المقسمة:\n'); disp(DD);

p2 = DD(1,1); term = 1;
for k = 2:n2
    term = term * (x - x2(k-1));
    p2 = p2 + DD(1,k)*term;
end
fprintf('نيوتن: p(x) = %s\n', char(expand(p2)));

المحاضرة 9: التفاضل العددي

🎯 الأهداف التعليمية

  1. اشتقاق صيغ الفروق المنتهية من متسلسلة تايلور
  2. المشتقة الأولى: أمامية، مركزية، خلفية
  3. المشتقة الثانية: أمامية، مركزية، خلفية
  4. تحليل دقة الخطأ O(h) و O(h²)

9.1 الأساس: تعريف المشتقة

f'(x) = lim(h→0) [f(x+h) - f(x)] / h

9.2 صيغ المشتقة الأولى

الصيغةالقانونرتبة الخطأ
أمامية (نقطتان)f'(x) ≈ [f(x+h) - f(x)] / hO(h)
مركزية (نقطتان)f'(x) ≈ [f(x+h) - f(x-h)] / (2h)O(h²) ✓ الأدق
خلفية (نقطتان)f'(x) ≈ [f(x) - f(x-h)] / hO(h)

9.3 صيغ المشتقة الثانية

الصيغةالقانونرتبة الخطأ
أمامية (3 نقاط)f''(x) ≈ [f(x+2h) - 2f(x+h) + f(x)] / h²O(h)
مركزية (3 نقاط)f''(x) ≈ [f(x+h) - 2f(x) + f(x-h)] / h²O(h²) ✓ الأدق
خلفية (3 نقاط)f''(x) ≈ [f(x) - 2f(x-h) + f(x-2h)] / h²O(h)

f(x) = x²·eˣ ، احسب f'(2) مع h = 0.01

% المحاضرة 9: التفاضل العددي - MATLAB
% ============================================
clc; clear;
f = @(x) x.^2 .* exp(x);
x0 = 2; h = 0.01;

% المشتقة الأولى
df_fwd = (f(x0+h) - f(x0)) / h;
df_ctr = (f(x0+h) - f(x0-h)) / (2*h);
df_bwd = (f(x0) - f(x0-h)) / h;

fprintf('المشتقة الأولى عند x=2:\n');
fprintf('  أمامية:  %.6f\n', df_fwd);
fprintf('  مركزية:  %.6f\n', df_ctr);

المحاضرة 10: التكامل العددي

🎯 الأهداف التعليمية

  1. قاعدة شبه المنحرف البسيطة والمركبة (Trapezoidal Rule)
  2. قاعدة سيمبسون البسيطة والمركبة (Simpson's Rule)
  3. مقارنة الدقة بين القواعد

10.1 قاعدة شبه المنحرف البسيطة

∫ₐᵇ f(x)dx ≈ (b-a)/2 × [f(a) + f(b)]

10.2 قاعدة شبه المنحرف المركبة

∫ₐᵇ f(x)dx ≈ (h/2) × [f(x₀) + 2·Σᵢ₌₁ⁿ⁻¹ f(xᵢ) + f(xₙ)]

حيث: h = (b-a)/n ، xᵢ = a + i·h

10.3 قاعدة سيمبسون البسيطة

∫ₐᵇ f(x)dx ≈ (b-a)/6 × [f(a) + 4·f((a+b)/2) + f(b)]

10.4 قاعدة سيمبسون المركبة

∫ₐᵇ f(x)dx ≈ (h/3) × [f(x₀) + 4·Σ(الفردي) f(xᵢ) + 2·Σ(الزوجي) f(xᵢ) + f(xₙ)]

حيث: h = (b-a)/n و n يجب أن يكون زوجياً

📝 مثال من الملف: القواعد البسيطة

∫₀¹ x·eˣ dx

f(0) = 0 ، f(0.5) = 0.5·e^0.5 ≈ 0.82436 ، f(1) = e ≈ 2.71828

شبه المنحرف: (1-0)/2 × [0 + 2.71828] = 1.35914

سيمبسون: (1-0)/6 × [0 + 4(0.82436) + 2.71828] = 1.00262

الحل الحقيقي (بالتكامل بالتجزئة): [xeˣ - eˣ]₀¹ = 1

خطأ شبه المنحرف: 0.359 | خطأ سيمبسون: 0.003

الخلاصة: سيمبسون أدق بكثير!

📝 مثال من الملف: القواعد المركبة (4 فترات)

∫₁² (1/x) dx

h = (2-1)/4 = 0.25

ixᵢf(xᵢ) = 1/xᵢ

% المحاضرة 10: التكامل العددي - MATLAB
% ============================================
clc; clear;
f = @(x) 1./x;
a = 1; b = 2; n = 4;
h = (b-a)/n;
x = a:h:b;
y = f(x);

% شبه المنحرف المركبة
I_trap = (h/2) * (y(1) + 2*sum(y(2:end-1)) + y(end));

% سيمبسون المركبة (n زوجي)
I_simp = (h/3) * (y(1) + 4*sum(y(2:2:end-1)) + 2*sum(y(3:2:end-1)) + y(end));

I_exact = log(b) - log(a);

fprintf('شبه المنحرف: %.6f (خطأ: %.6f)\n', I_trap, abs(I_exact-I_trap));
fprintf('سيمبسون:     %.6f (خطأ: %.6f)\n', I_simp, abs(I_exact-I_simp));
fprintf('الحقيقي:     %.6f\n', I_exact);

المحاضرة 11: المعادلات التفاضلية العادية (IVP)

🎯 الأهداف التعليمية

  1. صياغة مسألة القيمة الأولية (Initial Value Problem)
  2. تطبيق طريقة أويلر (Euler's Method)
  3. تطبيق طريقة رونج-كوتا من الرتبة الرابعة (RK4)
  4. مقارنة الدقة بين الطريقتين

11.1 مسألة القيمة الأولية (IVP)

أوجد y(x) إذا كان:

dy/dx = f(x, y) ، y(x₀) = y₀

11.2 طريقة أويلر (Euler's Method)

yₙ₊₁ = yₙ + h · f(xₙ, yₙ)

حيث: xₙ₊₁ = xₙ + h

الخطأ التراكمي: O(h) — دقة منخفضة

11.3 طريقة رونج-كوتا RK4

yₙ₊₁ = yₙ + (h/6)(k₁ + 2k₂ + 2k₃ + k₄)

k₁ = f(xₙ, yₙ)
k₂ = f(xₙ + h/2, yₙ + h·k₁/2)
k₃ = f(xₙ + h/2, yₙ + h·k₂/2)
k₄ = f(xₙ + h, yₙ + h·k₃)

الخطأ التراكمي: O(h⁴) — دقة ممتازة!

% ============================================
% المحاضرة 11: أويلر + RK4 - MATLAB
% ============================================
clc; clear;
f = @(x,y) y + x;  % dy/dx = f(x,y)
x0 = 0; y0 = 2;
xend = 1; h = 0.1;
x = x0:h:xend;
n = length(x);

% ─── طريقة أويلر ───
y_euler = zeros(1,n);
y_euler(1) = y0;
for i = 1:n-1
    y_euler(i+1) = y_euler(i) + h * f(x(i), y_euler(i));
end

% ─── طريقة RK4 ───
y_rk4 = zeros(1,n);
y_rk4(1) = y0;
for i = 1:n-1
    k1 = f(x(i), y_rk4(i));
    k2 = f(x(i)+h/2, y_rk4(i) + h*k1/2);
    k3 = f(x(i)+h/2, y_rk4(i) + h*k2/2);
    k4 = f(x(i)+h, y_rk4(i) + h*k3);
    y_rk4(i+1) = y_rk4(i) + (h/6)*(k1 + 2*k2 + 2*k3 + k4);
end

% ─── عرض النتائج ───
fprintf('  x   |  أويلر   |   RK4\n');
fprintf('──────────────────────────────\n');
for i = 1:n
    fprintf(' %.1f | %.7f | %.7f\n', x(i), y_euler(i), y_rk4(i));
end

% ─── رسم بياني ───
figure;
plot(x, y_euler, 'ro-', 'LineWidth', 2); hold on;
plot(x, y_rk4, 'bs-', 'LineWidth', 2);
grid on;
xlabel('x'); ylabel('y');
title('مقارنة طريقة أويلر و RK4');
legend('أويلر O(h)', 'RK4 O(h^4)');
